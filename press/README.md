## Publishing checklist (manual — needs your accounts)

1. **X (Twitter)**: paste `x_thread.md` as a thread (8-10 tweets).
2. **LinkedIn**: paste `linkedin_post.md` + attach benchmark screenshot.
3. **Medium**: paste `medium_article.md` (add cover image — the architecture diagram from README).
4. **Hacker News**: paste `hackernews_post.md` as text submission; join comments (HN loves honest limitations).
5. **Reddit**: r/MachineLearning — paste `reddit_ml_post.md`; r/speechrecognition, r/india, r/IndicLanguageTech too.
6. **Hugging Face**: the model repo itself (done) — share it from your HF dashboard feed.
7. **YouTube/Dev.to/Towards Data Science** (optional): adapt `medium_article.md`.

### SEO/AEO tips when pasting

- Keep the H1 exactly: `PolyWhisper — Hinglish ASR with LoRA Routing`
- Include the keywords naturally: Hinglish ASR, code-switching speech recognition,
  Hindi-English, Whisper fine-tuning, LoRA adapters, edge ASR, low-resource ASR
- Answer-form first lines (AEO): start with the "What is..." answer pattern.
